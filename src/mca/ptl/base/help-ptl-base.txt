host does, and this process has neither as configured. Its security
mechanisms are:

  %s

connects to one as before when that file says its release.

[server-closed-no-reply]
The PMIx server at:

  %s

closed the connection without answering this process's request to
connect.

The usual reason is that the server runs a different PMIx release and
does not have the wire format or security mechanism this process
offered. This process was given only the server's address, which does
not say what the server accepts, so it offered its own newest.

Give this process the server's rendezvous or report-URI file instead of
its address, as:

  file:<path>

That file says which release the server runs and, from recent releases
on, exactly what it accepts - so this process can choose a match.
