[unowned-peer]
A process at %s, an address of this host, asked to connect to this
PMIx server over TCP using the "native" security mechanism, claiming to
be uid %lu. The operating system has no established connection of that
process's in its table of TCP connections, so it cannot say who owns it,
and the request was refused.
#
[foreign-group]
A process owned by uid %lu asked to connect to this PMIx server as a
tool, claiming group id %lu. That user does not belong to that group, so
the request was refused.
#
